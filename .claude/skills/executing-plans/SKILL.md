# Executing Plans

Prefer subagent-driven-development when subagents are available.

1. Read the plan and review it critically; raise concerns before starting.
2. Create todos. For each task: mark in_progress, follow the steps exactly, run every verification, mark completed.
3. After all tasks: use finishing-a-development-branch.

Stop and ask (don't guess) on a blocker, missing dependency, unclear instruction, or repeated verification failure. Never implement on main/master without explicit consent.
