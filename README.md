# 🚀 OmniCommerce AI (OCA)
> **All-in-One Social Commerce & Omnichannel Platform**
> ລະບົບສູນກາງການຄ້າຜ່ານໂຊຊ້ຽວມີເດຍ, ແຕ່ງຮູບ AI, ດັກ CF Live, ສະຕ໋ອກສູນກາງ ແລະ ບັນຊີອັດສະລິຍະ ມາດຕະຖານສາກົນລະດັບ Enterprise (12 ໂມດູນ).

---

## 📌 ໂຄງສ້າງ 12 ໂມດູນຫຼັກຂອງ OmniCommerce AI

### ⚡ ສ່ວນດ່ານໜ້າ ແລະ ການຂາຍ (Sales & Frontline)
1. **Omnichannel Inbox:** ຮວມແຊັດສູນກາງ Facebook Messenger, Instagram DM, TikTok Messages, LINE OA ພ້ອມ AI Smart Reply ແລະ ເປີດບິນປິດການຂາຍໃນແຊັດ.
2. **Social Multi-Posting & Scheduler:** ຂຽນຄັ້ງດຽວ ໂພສ ແລະ ຕັ້ງເວລາລ່ວງໜ້າກະຈາຍລົງທຸກແພລັດຟອມ ພ້ອມ AI Copywriter ຊ່ວຍຂຽນແຄັບຊັນ & ແຮຊແທັກ.
3. **AI Image Studio:** Web Canvas Editor ແຕ່ງຮູບສິນຄ້າ, ຕັດພື້ນຫຼັງ 1-Click, ສ້າງສາກຫຼັງສະຕູດິໂອດ້ວຍ AI, ໃສ່ໂລໂກ້/ລາຄາ, ປັບຂະໜາດຮູບໃຫ້ຖືກຕາມແຕ່ລະໂຊຊ້ຽວ.
4. **Live & Post CF Engine:** ດັກຄອມເມັ້ນເວລາ Live ສົດ ແລະ ໂພສຂາຍ, ດັກຈັບລະຫັດ CF, ດຶງເຂົ້າ Inbox ອັດຕະໂນມັດ ພ້ອມອອກໃບບິນ QR Code ທີ່ມີເວລານັບຖອຍຫຼັງຕັດສະຕ໋ອກ.
5. **Promotion & Marketing Engine:** Flash Sale ໂມງນັບຖອຍຫຼັງ, Bundle ຊື້ຄູ່ຖືກກວ່າ, 1 ແຖມ 1 (BOGO), Abandoned Cart Auto-Recovery ດັກສົ່ງແຊັດຫາລູກຄ້າທີ່ປະຖິ້ມກະຕ່າ.
6. **Affiliate & Dropship Portal:** ລະບົບນາຍໜ້າ KOL/Influencer ແບ່ງ % ຄ່ານາຍໜ້າອັດຕະໂນມັດ ແລະ ລະບົບຕົວແທນຂາຍ Dropship (ເຫັນລາຄາສົ່ງ, ດາວໂຫຼດສື່).

### ⚙️ ສ່ວນສາງ ແລະ ການປະຕິບັດການ (Core & Operations)
7. **E-Commerce Storefront & Central Inventory:** ໜ້າເວັບໄຊຂາຍສິນຄ້າໂຫຼດໄວ ຮອງຮັບມືຖື 100% + ສະຕ໋ອກສູນກາງ Real-time (ຕັດສະຕ໋ອກພ້ອມກັນທັງເວັບ, ແຊັດ, ແລະ Live ປ້ອງກັນການຂາຍເກີນ).
8. **Smart Logistics Hub & Multi-Warehouse:** ຮອງຮັບຫຼາຍສາງ/ຫຼາຍສາຂາ, ລະບົບຍິງບາໂຄດກວດກ່ອນແພັກ (Scan-to-Verify), ເຊື່ອມຕໍ່ API ຂົນສົ່ງ, ພິມໃບປະໜ້າ Thermal 100x150mm ແລະ ສົ່ງເລກ Tracking ຫາແຊັດລູກຄ້າ.
9. **Automation Workflows & AI Slip Verification:** AI ອ່ານສະລິບໂອນເງິນ (OCR) ອັດຕະໂນມັດ ປັບສະຖານະບິນທັນທີ ແລະ ຕັ້ງກົດ IFTTT ແຈ້ງເຕືອນສະຕ໋ອກໃກ້ໝົດເຂົ້າ Telegram/LINE.

### 📊 ສ່ວນການວິເຄາະ ແລະ ບໍລິຫານ (Control & Intelligence)
10. **Analytics & Financial Reports:** ລາຍງານກຳໄລ-ຂາດທຶນສຸທິ (P&L), ຕົ້ນທຶນ COGS, ສິນຄ້າຂາຍດີ, ສິນຄ້າຄ້າງສະຕ໋ອກ (Deadstock), ປຽບທຽບຍອດຂາຍແຕ່ລະຊ່ອງທາງ.
11. **CRM & Customer Loyalty:** ຮວມປະຫວັດລູກຄ້າ 360°, ລະບົບສະມາຊິກ VIP (Bronze, Silver, Gold, Platinum), ສະສົມແຕ້ມແລກສ່ວນຫຼຸດ, ຈັດກຸ່ມລູກຄ້າ RFM.
12. **Multi-Role Team & Staff Management:** ແຍກສິດພະນັກງານ (RBAC), ວັດ KPI ຄວາມໄວໃນການຕອບແຊັດ ແລະ ຍອດປິດການຂາຍ, ບັນທຶກ Audit Trail ປ້ອງກັນການທຸຈະລິດ.

## 🛠️ Recommended Tech Stack

* **Frontend:** Next.js (App Router), TailwindCSS, Shadcn/ui, Fabric.js (Canvas Image Editor).
* **Monorepo:** pnpm workspaces + Turborepo.
* **Backend:** NestJS + TypeScript, WebSockets (Socket.io), BullMQ workers.
* **Database & Caching:** PostgreSQL + Prisma ORM, Redis + BullMQ (ຈັດຄິວ Webhook & Posting).
* **AI & Storage:** Gemini API (Multimodal Chat, Caption, OCR), Cloudflare R2 / AWS S3.

## ▶️ Getting Started

```bash
cp .env.example .env
pnpm install
pnpm infra:up      # ເປີດ PostgreSQL + Redis
pnpm dev
```

> ໝາຍເຫດ: `packages/database` (Prisma schema + Auth/RBAC + seed), `packages/config`, `packages/shared` ແລະ `apps/api` (login, RBAC, staff/roles, `/health`; module ອື່ນເປັນໂຄງເປົ່າ) ພ້ອມໃຊ້. `apps/worker`, `apps/admin`, `apps/storefront` ຍັງເປັນໂຄງເປົ່າ (Phase 0 ກຳລັງດຳເນີນ, ເບິ່ງ `docs/superpowers/specs/`). Test ຂອງ API ໃຊ້ Postgres + Redis ຈິງ (`pnpm infra:up`).
